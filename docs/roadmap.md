# Four releases

## V1 — Working investigator

Three real local fault scenarios and one healthy control; bounded read-only tools; strict diagnosis schema; deterministic independent grader; structured traces; local cost reservations; recorded evidence viewer; Python integration and desktop/mobile browser checks. Native execution and Docker Compose setup.

## V2 — Reliability evaluation

Expand to approximately 12 incidents, including insufficient evidence. Separate development cases from held-out evaluations. Repeat trials, compare baseline and improved configurations, inject tool timeouts/missing evidence and publish accuracy/cost/latency with denominators. No claims based only on a green demo.

## V3 — Security and controlled action

MCP exposure of selected tools, stronger permission boundaries, prompt injection in tool output, adversarial cases, and one tightly scoped remediation with backend-enforced human approval. Verify the actual state and retry behavior after the action.

## V4 — Recruiter showcase

Polished public hosting, documented comparison, downloadable scorecards, a concise walkthrough and portfolio integration. Prefer recorded evidence as the public default. Any bounded live demonstration requires an explicit operating budget and abuse controls. No automatic model spending from public traffic in V1.
