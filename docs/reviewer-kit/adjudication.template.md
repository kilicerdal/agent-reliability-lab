# Private adjudication worksheet

## Before sealing

- Reviewer and adjudicator
- Repository commit and planned repeats
- Incident ID, expected cause, and affected interval
- Alternative causes considered and the evidence that resolves them
- Most plausible weak citation and why it fails
- Minimum sufficient mechanism and configuration excerpts
- Unresolved disagreements and the pre-run adjudication decision

## After the run

Duplicate this table for each model. Use the frozen key to grade both states of each diagnosis.

| Incident / repeat | Cause correct | Initial support | Reviewed support | Review status | Failed claim and rationale |
| --- | --- | --- | --- | --- | --- |
| | | | | | |

Summarize repairs, preserved passes, lost passes, persistent failures, unsupported accepts, and correct abstentions. Record any disagreement with the frozen key separately.
